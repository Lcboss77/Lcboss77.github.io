FiveM resources / interfaces

Lcboss77 scripts and the screens players actually see

Server scripts in Lua with custom in-game interfaces built in HTML, CSS and JavaScript. Shops, admin tools, job systems and roleplay props for ESX and QBCore servers.

  • 30+ resources
  • Lua client and server
  • NUI HTML / CSS / JS
  • ESX + QBCore
  • oxmysql / SQL
  • Discord bot (Node.js)

lc-PetSystem

Pet System

An animal shop and pet care screen. Players browse breeds, fill a cart, then open a pet page that tracks six live needs and lists the commands the pet has learned.

  • Lua
  • NUI
  • ESX
  • SQL
  • Seven breeds with prices, cart and running total
  • Six stat rings for health, food, water, sun, activity and happiness
  • Learned commands played as animations straight from the UI
  • Custom art in the shop and info pages

lc-Companion

NPC Companion

A premium companion store paid for with donation coins. After purchase the player gets a command menu for the companion they now own.

  • Lua
  • NUI
  • Custom models (.ydd / .ymt)
  • Three companion types: mercenary, robot and animal
  • Coin balance and price sent live from the server
  • Five actions: instant heal, change appearance, call NPC, invisible mode, rewards

ItemManager

Item Manager

An admin panel for the server's item database. Staff list, search, edit and delete items without touching SQL, and every change is written to a log.

  • Lua
  • NUI
  • ox_inventory
  • Discord API
  • SQL
  • Edit form built from the table, so new database columns appear without code changes
  • 10 interface languages from English to Swedish
  • Stats for total items and item types
  • Action log with timestamps for every edit and delete
  • Settings for command name, ACE permission, image upload and list export
  • Discord profile of the signed-in staff member in the header

lc_Targetboosting

Death Contract Tablet

A criminal-job tablet with rank progression, a contract history and a leaderboard. Accepting a job opens a paper contract that the player signs, and the signature is stamped in blood.

  • Lua
  • NUI
  • ESX
  • Four ranks from Newbie to Elite Killer with progress bars
  • Contract paper filled from data: target, location, payment, instructions, map images
  • Signature effect with a red cross and splatter

lc-specialItems

Diving Oxygen Bar

A vertical oxygen meter for underwater play. The bar drains as the player's oxygen drops, changes colour as it gets dangerous, and bubbles drift up through it the whole time.

  • Lua
  • NUI
  • CSS animation
  • Colour by level: green above 50%, yellow from 20 to 50, red below 20
  • Live bubbles spawned at random sizes and positions, each one rising and fading
  • Smooth drain with an eased height transition on every update
  • Out of Oxygen! message when the level reaches zero

lc-commlist

Game Commands Panel

An in-game help panel that lists every command and keybind the server offers. The server sends the lists and the panel builds itself from them, so a new command shows up without changing the interface.

  • Lua
  • NUI
  • SQL
  • Two tabs: Commands with the slash command, Keybinds with the key
  • Empty states that say when no commands or keybinds exist
  • Closes with the X button or the Escape key

top_shooters

Top Shooters Leaderboard

A kill leaderboard that shows the ten best shooters on the server over a full-screen artwork background.

  • Lua
  • NUI
  • jQuery
  • Top 10 table with rank, name and kills, rebuilt on every update
  • Podium styling with a trophy and its own colour for first, second and third
  • Closes with the Escape key and tells the game script

BlackMarket

Black Market

A full-screen weapon shop built around a clear loop: browse, inspect, buy. It reads its data from the server and shows the stats of the weapon the player picks.

  • Lua
  • NUI
  • ESX
  • Black Market with weapon stats for damage, accuracy, fire rate and range

lc-fingscann

Fingerprint Scanner

A handheld device for roleplay. It reads a fingerprint and returns the person's record.

  • Lua
  • NUI
  • ESX
  • oxmysql
  • Scanner placed at map locations with a proximity marker and an interact prompt
  • Result card with name, age, address, occupation and mugshot support

Screens are captured from the real interface code running with sample data (names, prices, stats) at 1920 x 1080. In game they sit over the world.
